# KO-BRAS Architecture

## Platform
Garment = pihak pemberi pekerjaan.
Konveksi = pihak pelaksana produksi.
Ko-Bras = penghubung dan pengelola jaringan.

## Alur utama
1. Konveksi mendaftar sebagai mitra.
2. Ko-Bras memverifikasi organisasi.
3. Garment menerbitkan Surat Jalan.
4. Konveksi mengajukan pekerjaan.
5. Garment menentukan alokasi.
6. Barang diambil dan dikonfirmasi.
7. Produksi dilaporkan bertahap.
8. Barang dikembalikan dan diperiksa.
9. Garment menerima hasil akhir.

## Backend
Supabase PostgreSQL dengan Row Level Security.
