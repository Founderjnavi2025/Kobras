# KO-BRAS
Platform penghubung garment dan konveksi.

## Teknologi
- Supabase PostgreSQL
- Supabase Auth
- Supabase Storage
- Supabase Edge Functions
- HTML, CSS, JavaScript
- Vercel

## Modul
00. Core Identity
01. Business Verification
02. Business Network
03. Marketplace
04. Logistics
05. Production
06. Billing
07. Governance

## Prinsip
- Satu akun dapat menjadi anggota beberapa organisasi.
- Garment dapat membagi pekerjaan ke beberapa konveksi.
- Setiap organisasi hanya dapat mengakses data sesuai kewenangannya.
- Pembayaran produksi dilakukan langsung antar pihak.
